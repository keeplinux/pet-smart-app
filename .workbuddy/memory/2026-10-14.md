### 第十二轮：视角自动记忆 + 动态构图
- **视角持久化**：`VIEW_STORAGE_KEY = 'pet-smart-app:home-view'`；OrbitControls `'end'` 事件后 **800ms 防抖**（等 damping 惯性稳定）保存 `camera.position` 到 localStorage；启动时 `readSavedView()` 恢复用户最优视角（数据校验 x/y/z 均为 number，损坏回退默认 45° 视角 `DEFAULT_CAMERA {0, 5.6, 5.6}`）。cleanup 时 clearTimeout。
- **动态构图（取代 resize 固定 offset）**：`applyCompose()` 每帧调用（controls.update 后、render 前）——`ratio = clamp((MAX_DISTANCE - dist) / (MAX_DISTANCE - composeAnchor), 0, 1)`，`factor = 0.192 × ratio`；`composeAnchor` = 启动时相机距离（≈7.92）。拉近（dist < anchor）保持 0.192 海平面构图；拉远到 `MAX_DISTANCE = 9.6` 时 factor→0，星球完全居中。resize 只保留 aspect/size，也调一次 applyCompose。
- **灵敏度收紧**：`rotateSpeed 0.45`、`zoomSpeed 0.6`、`minDistance 4.6`、`maxDistance 9.6`——轻滑不会甩到很远的视角。
- preview-phone.html hint 补充视角记忆说明（iframe 与 dev server 同源，localStorage 记忆直接生效）。
- 验证：tsc / eslint / build 全通过。
