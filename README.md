# Pet Smart App

智能宠物设备用户端 App 原型工程，当前先完成手机端界面框架和智能饮水机核心页面。

## 当前框架

- 首页：家庭入口、今日饮水摘要、设备列表、快捷入口、底部导航
- 设备：已放入智能饮水机，预留智能投食机入口
- 饮水机详情：在线状态、水量、可用天数、开关/循环/设置、近 7 天趋势、今日饮水记录

## 技术栈

- Vite
- React
- TypeScript
- lucide-react

## 运行

```bash
npm install
npm run dev
```

默认访问地址：

```text
http://127.0.0.1:5173
```

## 构建检查

```bash
npm run lint
npm run build
```
